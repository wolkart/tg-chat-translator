# Spec Delta

## REMOVED Requirements

### Requirement: Статус по /start
**Reason**: `/start` теперь открывает панель настроек. Её главный экран показывает всё, что
показывал статус: подключение, право отвечать, языки, модель, «Написать первым». Сверху
добавлены BotFather, ключ с остатком и обращение, а под статусом — кнопки, которыми это
меняется.
**Migration**: требования «Панель открывается по /start», «Строки состояния» и «Подсказка
«Написать первым» по Inline Mode» в спеке `settings-panel`. Владельцу ничего делать не
нужно: команда та же.
