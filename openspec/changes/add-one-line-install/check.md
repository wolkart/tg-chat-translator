# Проверка: установка одной строкой

> Живая проверка — пишется вместе со спекой, проходится после сборки. Проверяется
> настоящей установкой по УСТАНОВКЕ, а не тестами. Каждый сценарий: что делаешь → что
> должно получиться → что получилось.

## Что нужно для проверки

- тестовый бот @aIrtem_tg_translator_bot и его токен; на время проверки бот автора на Mac
  не запущен;
- второй аккаунт Telegram (Timon), чтобы написать иностранцу и получить перевод;
- ключ OpenRouter — вставляется в панели;
- **Mac:** свой пользователь автора — на нём же показ для рилса. Бот разработки (`npm start`
  в каталоге продукта) перед этим остановлен: один бот — одна копия;
- **Windows** — по желанию автора, позже, MVP не держит: машина или виртуалка с
  Windows 10/11, обычный пользователь без прав администратора, если получится — с
  кириллицей в имени;
- **сервер:** сервер автора с Ubuntu, вход по SSH;
- ветка `feat/one-line-install` запушена (по команде автора).

## Ревью перед «готово»

- [ ] ревью кода — замечания закрыты
- [ ] ревью безопасности — скрипты скачивают и исполняют код, пишут токен
- [ ] ревью по чек-листу стандартов кита — все «нет» закрыты
- [ ] обычная работа и «ломаем нарочно» пройдены, расхождений со спекой нет
- [ ] камни, найденные по ходу, записаны карточками; подтверждённые живьём — со статусом ✅
