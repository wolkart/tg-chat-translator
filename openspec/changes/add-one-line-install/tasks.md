## 1. Бот: когда поднимается сам, а когда засыпает

- [ ] 1.1 `classifyStop(error)` → `sleep-conflict` | `sleep-token` | `retry` | `crash` (design, решение 6). Проверка: тесты на образцах ошибок grammY: 409 «terminated by other getUpdates request», 401 «Unauthorized», сетевая ошибка `HttpError`, неизвестная ошибка. 409 из-за вебхука — не `sleep-conflict`.
- [ ] 1.2 Старт в `main.ts`: `getMe` без сети повторяется с паузой 5 → 10 → 30 → 60 с и пишет в журнал одну строку. 401 — «Telegram не принял токен бота. Поставьте бота заново командой из README», и бот засыпает. Проверка: тесты на подменённом `getMe` — сеть пропала дважды, потом ответ, и бот стартует; 401 не повторяется и процесс не завершается.
- [ ] 1.3 Опрос: `bot.start` упал с 409 — владельцу «Бот остановился на <место>: этот же бот запущен ещё в одном месте. Работать должна одна копия — лишнюю удалите командой из README», с 401 — строка в журнал. После этого бот засыпает. Другие ошибки завершают процесс с кодом 1. Место: «Mac (<имя компьютера>)», «Windows (<имя компьютера>)», «сервере». Проверка: тесты — текст по каждой системе; при 409 ровно одно сообщение владельцу и ни одного нового опроса; при `crash` — код выхода 1 (сценарии «Сначала Mac, потом сервер», «Токен отозван»).
